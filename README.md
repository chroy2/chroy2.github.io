# chroy2.github.io

My personal site, hosted on GitHub Pages: https://chroy2.github.io

Plain HTML, CSS, and a little JavaScript. No build step.

- `index.html`: the page
- `style.css`: styles, with light and dark themes
- `main.js`: particle portrait, theme toggle, and the interactive shell (type `help`)
- `assets/`: portrait and résumé PDF

Run it locally with any static server, e.g. `python3 -m http.server`, then open http://localhost:8000.
Opening `index.html` directly from disk works, but the particle portrait falls back to a static image.
